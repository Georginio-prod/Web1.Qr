## 📌 Présentation

**Mon tout premier défi Frontend Mentor** (juin 2024) : une carte centrée contenant un QR code, un titre et un court texte. L'exercice de base pour apprendre à centrer un élément, arrondir des coins et gérer une ombre portée.

Ce projet fait partie de ma **première série de défis Frontend Mentor (juin–juillet 2024)**,
réalisée en **HTML et CSS purs**, sans outil de build ni framework, pour consolider les
fondamentaux avant de passer à Sass, Tailwind puis Vue.

## ✨ Fonctionnalités

- Carte blanche centrée verticalement et horizontalement (Flexbox).
- Image du QR code avec coins arrondis.
- Typographie Outfit, palette du style guide.
- Responsive mobile / desktop.

## 🛠️ Stack

| Élément | Détail |

| Styles | CSS3 (Flexbox / Grid, media queries), Google Fonts |

## 🚀 Lancement

Aucune installation : cloner le dépôt et ouvrir le fichier HTML dans un navigateur.

```bash
git clone https://github.com/Georginio-prod/Web1.Qr.git
```

Pour un rechargement automatique, l'extension **Live Server** de VS Code fonctionne très bien.
